## 📞 Support

### Having Issues?
1. Check [THEMES_GUIDE.md - Support](./THEMES_GUIDE.md#-support)
2. See troubleshooting section below

### Troubleshooting

**"I don't see new themes in dropdown"**
- Hard refresh: Ctrl+Shift+R
- Clear browser cache
- Try in incognito window

**"Themes aren't switching"**
- Check browser console for errors
- Try in a different browser
- Clear localStorage

**"Colors look different"**
- This might be your monitor calibration
- Try in different lighting
- Check on mobile device

**"Still having issues?"**
- Check browser console
- Try incognito mode
- Report issue with browser/OS info
