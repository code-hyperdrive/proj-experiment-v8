================================================================================
                          GETTING STARTED (5 STEPS)
================================================================================

1. INSTALL DEPENDENCIES
   $ cd automation
   $ npm install
   (or: npm run setup)

2. START YOUR APP
   $ python3 -m http.server 3000
   (in separate terminal, from project root)

3. RUN ALL TESTS
   $ npm test

4. VIEW RESULTS
   $ open reports/test-report.html

5. (OPTIONAL) EXPLORE REPORTS
   $ open reports/e2e-report/index.html

================================================================================
                            QUICK COMMANDS
================================================================================

# Full test suite (4-5 minutes)
npm test

# Quick tests without E2E (1-2 minutes)
npm run test:fast

# Individual test suites
npm run test:data              # Data validation only
npm run test:unit              # Unit tests only
npm run test:e2e               # Browser tests only
npm run test:stations          # Station health only

# Alternative launcher
./run-tests.sh                 # Run all tests
./run-tests.sh fast            # Quick test
./run-tests.sh data            # Data validation
./run-tests.sh help            # Show options

# Setup & verification
npm run setup                  # Install & verify environment

# Skip slow tests during development
node run-all-tests.js --skip-e2e
node run-all-tests.js --skip-stations

# Verbose output (debug)
npm run test:all
DEBUG=* npm test

================================================================================
                            CONFIGURATION OPTIONS
================================================================================

Environment Variables (create .env file):

# Application
BASE_URL=http://localhost:3000         # App URL for E2E tests
NODE_ENV=test                          # Environment

# Station health checks
CONCURRENCY=40                         # Parallel checks (default: 40)
TIMEOUT=8000                           # Connection timeout in ms
ONLY_ENABLED=false                     # Test only enabled stations

# Testing
VERBOSE=false                          # Verbose output
CI=false                              # CI/CD mode
SKIP_E2E=false                        # Skip browser tests
SKIP_STATIONS=false                   # Skip station checks

# Logging
DEBUG=false                           # Debug mode
LOG_LEVEL=info                        # Log level

Usage:
  $ BASE_URL=http://localhost:8080 npm test
  $ CONCURRENCY=60 npm run test:stations
  $ TIMEOUT=15000 npm run test:stations

================================================================================
                            TROUBLESHOOTING TIPS
================================================================================

ISSUE: "npm: command not found"
FIX: Install Node.js 18+ from https://nodejs.org/

ISSUE: "Port 3000 already in use"
FIX: lsof -ti:3000 | xargs kill -9

ISSUE: "Tests timeout"
FIX: TIMEOUT=15000 npm test

ISSUE: "E2E tests fail"
FIX: npm run test:all (verbose output)
     open reports/e2e-report/index.html (see details)

ISSUE: "npm install fails"
FIX: rm -rf node_modules && npm install
